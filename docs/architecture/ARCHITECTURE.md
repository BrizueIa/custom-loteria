**Status:** Approved

## 1. System Overview

Custom Lotería is an interactive, browser-based Mexican Lotería game engine and board generator. It is designed around two core workflows:

1. **Digital Caller (*El Cantador*):** An automated and manual card calling environment equipped with audio narration, traditional lottery verses/rhymes, celebration triggers, and deck tracking.
2. **Board Studio & PDF Generator (*Tablas a PDF*):** A visual studio to design custom decks, configure card layouts, and generate mathematically permuted printable player boards exported as multi-page PDFs.

## 3. Core Engine Mechanics

### 3.1 Board Generation & Permutation
* Player boards (*tablas*) are algorithmically generated by selecting subsets of cards from the active deck.
* A Fisher-Yates shuffle guarantees uniform card distribution across boards.
* Configurable duplicate prevention ensures boards remain distinct in multi-player games.

### 3.2 PDF Generation Pipeline
* Rendered board grids are captured via `html2canvas` at high DPI.
* Images are placed onto standard letter or A4 pages via `jsPDF`, producing print-ready documents ready for game nights.

### 3.3 Audio & Caller Engine
* Supports multi-voice synthesized calling using Web Speech API with fallback to audio assets.
* Interval timers control auto-calling with pausing and manual card advancement.
